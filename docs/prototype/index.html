03 / ABOUT

学无止境，
彼此为师。

“认真倾听，让理解发生。”

Laoshi 取“老师”之音。师说相信，每个人都有值得学习的经验；保持求知，分享所学，通过真诚沟通理解彼此。这里收录从真实问题出发的软件作品，也是持续学习与实践的记录。

在 laoshi.chat，Laoshi 是彼此为师的学习态度，chat 是倾听与表达的沟通方式。将所学付诸实践，让作品成为分享经验、连接彼此的起点。

  • 01
    终身求知

    从真实问题出发，在实践中学习，持续检验与修正自己的认识。

  • 02
    彼此为师

    分享所学与所作，尊重不同的经验，也向每一位使用者学习。

  • 03
    以诚对话

    认真倾听，清晰表达，在交流中理解需求，让作品回应真实生活。

做软件时，我依然偏爱本地优先、用途清晰与长期维护：让数据尽可能留在自己的设备里，让每件作品专注解决问题，并在日常使用中不断打磨。
